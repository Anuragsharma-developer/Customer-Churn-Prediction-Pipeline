# Customer-Churn-Prediction-Pipeline
📊 Churn Prediction using Machine Learning
🧠 Overview
This project focuses on predicting customer churn using Machine Learning models.
The objective is to analyze customer data, identify behavioral patterns, and predict whether a customer will leave the service or continue using it.
By leveraging data preprocessing, feature encoding, and ML algorithms, this model can help companies reduce customer attrition and improve retention strategies.

⚙️ Features
Data Cleaning and Preprocessing
Handling Missing and Categorical Data
Label Encoding for Object Columns
Model Training and Evaluation
Saving Encoders using Pickle for Future Predictions
Data Visualization and Insights
🧰 Technologies Used
Python 🐍
Pandas, NumPy → Data manipulation and analysis
Matplotlib, Seaborn → Data visualization
Scikit-learn (sklearn) → Label encoding, model building, evaluation
Pickle → Model/Encoder serialization
